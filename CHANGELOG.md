# Changelog

Much of the code and documentation is written by Claude, Anthropic's AI model, using Claude Code (see "Built with AI
assistance" in the README).

## First public release (October 2026)

- A client-side FERS household retirement planner: the FERS annuity and supplement, TSP, IRAs, brokerage, checking
  and money market, both spouses' Social Security, federal, state and foreign tax, RMDs, Roth conversions, survivor
  scenarios, Monte Carlo and planning tools. See the README for every assumption.
- Statutory values are 2026 law as of October 2026.
- A made-up default household to start from; replace it with your own numbers.
- Public domain under The Unlicense (`LICENSE`). Use it at your own risk; it is not financial, tax, investment or
  legal advice.
