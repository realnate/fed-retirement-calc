# Changelog

Much of the code and documentation is written by Claude, Anthropic's AI model, using Claude Code (see "Built with AI
assistance" in the README).

## First public release (October 2026)

- A client-side retirement planner for a household with one or two people, either or both federal employees under
  FERS: each person's pay, workplace plan (the TSP or a 401(k)), IRAs, FERS annuity and supplement or another pension,
  and Social Security; plus brokerage, checking and money market, federal, state and foreign tax, RMDs, Roth
  conversions, survivor scenarios, Monte Carlo and planning tools. See the README for every assumption.
- Statutory values are 2026 law as of October 2026.
- A made-up default household to start from; replace it with your own numbers.
- Public domain under The Unlicense (`LICENSE`). Use it at your own risk; it is not financial, tax, investment or
  legal advice.
